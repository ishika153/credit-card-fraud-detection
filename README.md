Credit Card Fraud Detection using XGBoost and SMOTE

## Objective
Detect fraudulent credit card transactions using XGBoost
on a highly imbalanced dataset.

## Techniques Used
- Data Cleaning
- Train-Test Split
- SMOTE
- XGBoost
- Precision
- Recall
- F1 Score
- ROC-AUC
- Decision Threshold Tuning
- Feature Importance

## Best Result
Best tested threshold: 0.9

Precision: 0.9706
Recall: 0.9429
F1 Score: 0.9565

## Feature Importance
The most important feature for the trained XGBoost model was V14.
